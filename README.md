# FourthHaven Team Hub v19

GitHub-ready copy of the FourthHaven Team Hub v19 portal.

## GitHub Pages
This folder already uses `index.html` as the root page.

Upload the **contents of this folder** to the root of your GitHub repository:
- `index.html`
- `README.md`

Then in GitHub go to **Settings → Pages → Build and deployment → Deploy from a branch**, select your main branch and `/ (root)`, then save.

## Important
This package preserves the supplied v19 portal exactly; the only change is renaming the original HTML file to `index.html` so GitHub Pages can load it at the repository root.
